# Pelatihan Administrasi Akademik Digital dan Pemutakhiran Data PDDikti

Halaman belajar mandiri (LMS) untuk Tata Usaha Program Studi Manajemen Pendidikan Islam, FITK UIN Sunan Kalijaga Yogyakarta.

Unit kompetensi: N.82ADM00.064.2 Mengoperasikan Sistem Informasi (SKKNI Kepmenaker Nomor 109 Tahun 2024).

## Isi

- `index.html`: halaman LMS (modul mandiri KUK 2.1 dan KUK 3.1, kuis, dan daftar bahan)
- `bahan/Modul_Pelatihan.pdf`: modul Bab 1–7
- `bahan/Lembar_Kerja_Peserta.pdf`: lembar kerja Sesi 2 (luring)
- `bahan/Data_Simulasi_Mahasiswa.xlsx`: data latihan studi kasus validasi
- `bahan/Slide_Pelatihan_Sesi_1_dan_2.pdf`: slide Sesi 1 dan Sesi 2

Semua nama, NIM, dan dosen dalam data latihan adalah fiktif. Jawaban latihan di halaman LMS hanya tersimpan di browser perangkat masing-masing peserta.
